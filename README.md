# AuthSpring
A full-stack authentication and user management system built with Spring Boot, React, Spring Security, JWT, and MySQL.

## Features
- User Registration & Login
- JWT Authentication
- Spring Security
- Role-Based Authorization
- Email Verification
- Forgot Password
- Password Reset
- User Profile Management
- Protected Routes
- REST APIs

## Tech Stack

### Backend
- Java
- Spring Boot
- Spring Security
- Spring Data JPA
- Hibernate
- MySQL
- JWT

### Frontend
- React.js
- JavaScript
- Axios
- React Router
- Vite

### Tools
- Maven
- Git
- GitHub
